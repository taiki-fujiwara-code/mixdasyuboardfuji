# グループ クチコミ返信設定 画面仕様書

**バージョン**: 1.0  
**作成日**: 2026-06-15  
**対象機能**: グループのクチコミ管理 — 一括返信・自動返信のツール上直接設定

---

## 1. 概要・背景

### 1.1 目的

現状、グループ単位でのクチコミ一括返信・自動返信の設定はインポート（CSV/Excel）を通じてのみ行える。  
本機能では、ツール画面上で直接 **一括返信** および **自動返信ルール** を設定・管理できるようにし、運用効率を大幅に改善する。

### 1.2 ターゲットユーザー

| ユーザー種別 | 主な操作 |
|-------------|---------|
| グループ管理者（full/master ロール） | 一括返信の実行、自動返信ルールの作成・編集・削除 |
| 編集ユーザー（edit ロール） | 一括返信の実行、自動返信ルールの参照 |
| 閲覧ユーザー（view ロール） | 参照のみ |

### 1.3 既存機能との関係

| 既存画面 | 本機能との関係 |
|---------|--------------|
| `groups/reviews.html.erb` | 本機能の入口（タブ追加） |
| `pattern_auto_replies/new.html.erb` | 単店舗向け。本機能はグループ横断版 |
| `ai_advices/` | AI返信生成。本機能と連携して活用 |

## 4. タブ2「一括返信」仕様

### 4.1 画面レイアウト（ワイヤーフレーム）

```
┌──────────────────────────────────────────────────────────────────┐
│ 【一括返信】                                                       │
│                                                                    │
│ ■ Step 1: クチコミを絞り込む                                       │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ 店舗         [ドロップダウン: すべて / 店舗名選択]               │  │
│ │ 評価         ☆☆☆☆☆ チェックボックス（複数選択）               │  │
│ │ 返信ステータス [未返信▼]  期間 [yyyy/mm/dd〜yyyy/mm/dd]         │  │
│ │ キーワード    [テキスト入力]                [🔍 絞り込む]        │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│ ■ Step 2: 返信するクチコミを選択する                               │
│ ┌─┬──────┬───────┬─────┬─────────────────────────────────────┐  │
│ │☑│店舗名 │投稿日  │評価  │クチコミ本文（抜粋）                  │  │
│ ├─┼──────┼───────┼─────┼─────────────────────────────────────┤  │
│ │☐│A店   │06/10  │★★★★☆│「スタッフの対応が…」               │  │
│ │☐│B店   │06/09  │★★★☆☆│「駐車場が…」                       │  │
│ │☐│C店   │06/08  │★★★★★│「とても良かった…」                 │  │
│ └─┴──────┴───────┴─────┴─────────────────────────────────────┘  │
│  [全選択] [選択解除]    選択中: 0件 / 全 32 件    [< 1 2 3 >]    │
│                                                                    │
│ ■ Step 3: 返信文を設定する                                         │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ 返信モード  ● 共通文を入力  ○ テンプレートから選択             │  │
│ │                                                              │  │
│ │ [共通返信文テキストエリア 300文字]          残り 300 文字      │  │
│ │                                                              │  │
│ │ [🤖 AIで返信文を生成する]                                     │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│ ⚠ 選択中の 0 件のクチコミに返信します。この操作は取り消せません。  │
│                               [キャンセル]  [一括返信を実行する ▶] │
└──────────────────────────────────────────────────────────────────┘
```

### 4.2 絞り込み条件

| 項目 | 種別 | 選択肢 / 入力 | デフォルト |
|------|------|-------------|----------|
| 店舗 | ドロップダウン（複数選択可） | グループ内の全店舗 | すべて |
| 評価 | チェックボックス | ★1〜★5（複数選択可） | すべて |
| 返信ステータス | ドロップダウン | すべて / 未返信 / 返信済み | 未返信 |
| 期間 | 日付範囲ピッカー | 投稿日のFrom/To | 過去30日 |
| キーワード | フリーテキスト | クチコミ本文を部分一致検索 | 空 |

### 4.3 クチコミ一覧テーブル

| カラム | 説明 |
|-------|------|
| チェックボックス | 返信対象の選択 |
| 店舗名 | クリックでその店舗の詳細へ遷移 |
| 投稿日 | yyyy/mm/dd 表示 |
| 評価 | ★アイコン（1〜5） |
| クチコミ本文（抜粋） | 最大100文字 + 「もっと見る」ツールチップ |
| 返信ステータス | バッジ：未返信（オレンジ）/ 返信済み（グリーン） |

- ページネーション: 1ページ20件、Kaminari で実装
- 返信済みクチコミは選択不可（チェックボックスdisabled）

### 4.4 返信モード

#### モード1: 共通文を入力
- テキストエリア（最大300文字）
- リアルタイム文字数カウント表示
- 「🤖 AIで返信文を生成する」ボタン → 後述のAI生成パネルを展開

#### モード2: テンプレートから選択
- 事前登録済みの返信テンプレート一覧をドロップダウン表示
- テンプレート選択後、テキストエリアに本文を自動挿入（編集可）

### 4.5 AI返信文生成パネル（モード1押下時にスライド展開）

```
┌──────────────────────────────────────────────────────────────┐
│ 🤖 AI返信文の生成                                              │
│ トーン  [丁寧・感謝▼]                                          │
│ 文字数  [〜100文字▼]                                           │
│ 追加指示 [任意: 「割引について触れる」等]                        │
│                          [生成する]  ← クリックで返信文を生成   │
└──────────────────────────────────────────────────────────────┘
```

- 生成後、上のテキストエリアに結果を自動反映（編集可）
- 複数件選択時: 「各クチコミの内容に合わせて個別生成する」オプション

### 4.6 実行フロー

```
選択済みクチコミ確認 → 確認ダイアログ → Sidekiq ジョブでバックグラウンド処理
                                          ↓
                              async_tasks/index.html.erb でステータス確認可能
```

- 大量件数（100件超）の場合: 非同期処理（BulkReviewReplyWorker）
- 完了後: メール通知 + 画面上のバナー通知

### 4.7 エラーハンドリング

| エラーケース | 表示 |
|-------------|------|
| 0件選択で実行 | インラインエラー：「返信するクチコミを選択してください」 |
| 返信文が空 | インラインエラー：「返信文を入力してください」 |
| Google API エラー | 個別のエラーログ。成功分は処理継続 |
| 権限なし | 403ページへリダイレクト |

### 5.4 ルール設定項目定義

| 項目 | 必須 | 型 | バリデーション |
|------|------|-----|--------------|
| ルール名 | ○ | string | 最大50文字 |
| 適用対象 | ○ | enum: all / selected | — |
| 選択店舗 | 条件付き | array[Branch.id] | 適用対象=selected の場合必須、1件以上 |
| 評価条件 | △ | array[1..5] | 未設定=すべての評価 |
| キーワード条件 | △ | array[{word, match_type}] | 各キーワード最大50文字、最大10個 |
| 返信済みスキップ | ○ | boolean | デフォルト: true |
| 返信モード | ○ | enum: template / fixed | — |
| テンプレートID | 条件付き | integer | 返信モード=template の場合必須 |
| 固定返信文 | 条件付き | text | 返信モード=fixed の場合必須、最大300文字 |
| ステータス | ○ | boolean | デフォルト: true（有効） |
| 適用タイミング | ○ | integer | 0（即時）〜 24（時間後）、デフォルト: 0 |
| 1日の返信上限 | ○ | integer / null | 0=無制限、1〜9999 |

### 5.5 キーワード条件の仕様

- マッチタイプ: **含む** / **含まない**
- 複数キーワードは **OR 条件**（例：「駐車場」含む OR「待ち時間」含む）
- 評価条件とキーワード条件は **AND 条件**（例：★4〜★5 かつ「ありがとう」含む）

### 5.6 ルールの優先順位と競合処理

- 複数ルールが同一クチコミにマッチした場合: **優先度の高いルール（上位のもの）のみ適用**
- 優先度は一覧画面でのドラッグ＆ドロップで変更可能
- 優先度の低いルールは自動でスキップ（ログに記録）

### 5.7 ルール削除の仕様

- 削除確認ダイアログ表示（「このルールを削除しますか？実行中の処理には影響しません。」）
- 論理削除（`deleted_at` タイムスタンプ）
- 削除後は一覧から非表示

## 7. データモデル（新規テーブル設計案）

### 7.1 group_review_auto_reply_rules（自動返信ルール）

```ruby
create_table :group_review_auto_reply_rules do |t|
  t.references :group,       null: false, foreign_key: true
  t.string     :name,        null: false, limit: 50
  t.integer    :target_type, null: false, default: 0  # enum: all=0, selected=1
  t.string     :rating_conditions              # JSON: [1,2,3,4,5]
  t.string     :keyword_conditions             # JSON: [{word:"...", match_type:"include"}]
  t.boolean    :skip_replied, null: false, default: true
  t.integer    :reply_mode,  null: false, default: 0  # enum: template=0, fixed=1
  t.references :review_reply_template, foreign_key: true
  t.text       :fixed_reply_body
  t.boolean    :active,      null: false, default: true
  t.integer    :delay_hours, null: false, default: 0
  t.integer    :daily_limit               # null=無制限
  t.integer    :priority,    null: false, default: 0
  t.datetime   :deleted_at
  t.timestamps
end
```

### 7.2 group_review_auto_reply_rule_branches（適用店舗の中間テーブル）

```ruby
create_table :group_review_auto_reply_rule_branches do |t|
  t.references :group_review_auto_reply_rule, null: false, foreign_key: true
  t.references :branch, null: false, foreign_key: true
  t.timestamps
end
```

### 7.3 review_reply_templates（返信テンプレート）

```ruby
create_table :review_reply_templates do |t|
  t.references :group, null: false, foreign_key: true

  t.text   :body,        null: false
  t.string :memo,        limit: 100
  t.datetime :deleted_at
  t.timestamps
end
```

### 7.4 group_review_bulk_reply_logs（一括返信ログ）

```ruby
create_table :group_review_bulk_reply_logs do |t|
  t.references :group,  null: false, foreign_key: true
  t.references :user,   null: false, foreign_key: true
  t.integer    :total_count,   null: false
  t.integer    :success_count, default: 0
  t.integer    :failed_count,  default: 0
  t.integer    :status, null: false, default: 0  # enum: pending=0, processing=1, completed=2, failed=3
  t.text       :reply_body
  t.datetime   :completed_at
```

## 9. UX/UI 設計方針

### 9.1 デザイン原則

| 原則 | 具体的方針 |
|------|-----------|
| **ステップ化** | 一括返信は3ステップ構成で迷わない導線 |
| **即時フィードバック** | チェックボックス操作と連動して選択件数をリアルタイム更新 |
| **破壊的操作の防護** | 一括実行前に「X件に返信します」確認ダイアログ必須 |
| **非同期処理の可視化** | 大量処理時はプログレスバー + 非同期タスク一覧へ誘導 |
| **空状態の配慮** | ルール未設定・クチコミ0件それぞれに適切な空状態メッセージ |

### 9.2 レスポンシブ対応

- PC（1280px以上）: 全カラム表示
- タブレット（768px〜1279px）: テーブル横スクロール
- スマートフォン（〜767px）: 管理画面のため最小限対応（警告バナー表示）

### 9.3 インタラクション詳細

#### 一括返信: チェックボックス操作

- ヘッダーの「全選択」: フィルタ結果の全件をチェック（返信済みを除く）
- 個別チェック: 即時カウント更新（「選択中: N件」）
- 100件超選択時: 黄色のバナー「大量処理のため完了まで数分かかる場合があります」

#### 自動返信: ステータストグル

- ON/OFF をインライン切り替え（ページリロードなし）
- OFF に変更時: 「このルールを無効にしますか？」確認トースト（3秒でキャンセル可）

#### ルールの並べ替え

- ドラッグハンドル（`⋮⋮`）をドラッグ＆ドロップで並べ替え
- ドロップ後に PATCH /reorder を非同期送信
- 視覚的フィードバック: ドラッグ中は行がゴースト表示

### 9.4 通知・フィードバック

| シナリオ | フィードバック |
|---------|--------------|
| 一括返信 完了（少量） | 画面上部に緑バナー「N件の返信が完了しました」（5秒後自動非表示） |
| 一括返信 完了（非同期） | メール通知 + 非同期タスク一覧にステータス表示 |
| 一括返信 一部失敗 | 黄バナー「N件成功 / M件失敗。失敗詳細はログを確認してください」 |
| ルール保存 完了 | トースト通知「ルールを保存しました」 |
| ルール削除 完了 | トースト通知「ルールを削除しました」 |
| API エラー | 赤バナーでエラーメッセージ表示 |

```ruby
class Groups::AutoReplyRuleContract < ApplicationContract
  params do
    required(:name).filled(:string, max_size?: 50)
    required(:target_type).filled(:integer, included_in?: [0, 1])
    optional(:branch_ids).array(:integer)
    optional(:rating_conditions).array(:integer)
    optional(:keyword_conditions).array(:hash)
    required(:reply_mode).filled(:integer, included_in?: [0, 1])
    optional(:template_id).maybe(:integer)
    optional(:fixed_reply_body).maybe(:string, max_size?: 300)
    required(:active).filled(:bool)
    required(:delay_hours).filled(:integer, gteq?: 0, lteq?: 24)
    optional(:daily_limit).maybe(:integer, gteq?: 1)
  end

  rule(:branch_ids) do
    key.failure("店舗を1件以上選択してください") if values[:target_type] == 1 && values[:branch_ids].blank?
  end

  rule(:fixed_reply_body) do
    key.failure("返信文を入力してください") if values[:reply_mode] == 1 && values[:fixed_reply_body].blank?
  end
```
